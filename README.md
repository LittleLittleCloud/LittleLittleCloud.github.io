Personal Website for my portfolio and blog. Built with Next.js, TypeScript, Tailwind CSS, and Shadcn-UI.

## GitHub Pages Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions. To ensure proper deployment:

1. Go to your repository **Settings** → **Pages**
2. Under **Build and deployment**, set the **Source** to **GitHub Actions**
3. The site will be automatically deployed when changes are pushed to the `main` branch

If you see the README.md content instead of the Next.js site, it means the GitHub Pages source is incorrectly set to "Deploy from a branch". Change it to "GitHub Actions" to fix this issue.
